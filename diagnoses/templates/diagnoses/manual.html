1. Diagnose Patient

Essential

Use the main diagnosis page to run symptom-based inference with clear reasoning output.

  1. Select all present symptoms.
  2. Review suggested symptoms and add relevant ones.
  3. Click Analyze Symptoms.
  4. Review confidence, matched symptoms, and missing symptoms per prediction.
  5. Open the info tooltip to inspect inference logic.

2. Export Report

Pro Tip

Generate documentation quickly for handoff, audit, or academic submission.

Action: Click Export Report to download a `.txt` case summary file.

3. Knowledge Base Manager

Staff only

Staff and superusers can tune the inference engine by adding diseases, symptoms, and rules.

  • Add disease entries and descriptions.
  • Add symptoms to expand your clinical vocabulary.
  • Define rules: a disease plus one or more required symptoms.
  • Only superusers can save rules after verifying clinical validity.

4. Troubleshooting

Tip: If there are no matches, update the KB with relevant rules or add missing symptoms first.
